\section{Test and Evaluation}

The requirement of this project is to perform drawing task within position error 10\% range and able to do force control. RMSE statistic method can be used to find the average position error occurs on the system when UR5 done drawing task. With RMSE calculation code, Computer can average the RMSE of each joint over time while UR5 is operated drawing task and when UR5 is done drawing task. \textbf{The average position RMSE of this control system are 0.0022 radian or 1.9\% error from joint limit}.
